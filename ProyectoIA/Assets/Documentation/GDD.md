# Game Design Document — Proyecto IA

## 1. Concepto

Juego 3D educativo/formativo ambientado en un mundo donde el jugador
resuelve desafíos prácticos de programación, SQL, redes y Linux
dentro de un entorno interactivo.

Plataforma objetivo: PC y móvil.
Motor: Unity (Universal Render Pipeline).

## 2. Gameplay

El jugador controla un personaje en tercera persona que explora
escenarios y resuelve desafíos técnicos.

Bucle principal (a definir en detalle):
- Explorar entorno
- Interactuar con terminales/objetos
- Resolver desafío
- Obtener recompensa/progreso

## 3. Tipos de desafíos

- Programación (editor de código + compilación segura + tests)
- SQL (editor + base de datos de prueba + validación)
- Redes (topología + configuración + simulación)
- Linux (comandos + entorno simulado)
